# Resume tailoring

Codex creates the tailoring packet and proposal internally, then invokes the deterministic renderer. Reference verified evidence IDs for every accomplishment; never introduce unsupported skills, tools, dates, metrics, or experience. LIGHT mostly reorders, STANDARD conservatively rewrites and selects, and DEEP adds companion drafts. The renderer—not the model—owns formatting. Show the user the rendered artifacts and important changes, not the intermediate JSON.
