# Onboarding

Codex runs the onboarding packet and setup commands internally. Draft only supported facts, use `UNKNOWN` for uncertainty, and ask concise follow-ups for required preferences. Show the user a readable profile review rather than JSON. After they confirm it is accurate, save the reviewed profile and preserve the original resume under the ignored private data directory.
