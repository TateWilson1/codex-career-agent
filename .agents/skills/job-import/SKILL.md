# Job import

Codex accepts a URL, pasted posting, or attached structured file and runs the import internally. Require company and title. Preserve source identifiers, canonical URLs, and the complete original posting. Review duplicate updates rather than merging separate openings based only on title. Report the imported role and any duplicate decision in ordinary language.
