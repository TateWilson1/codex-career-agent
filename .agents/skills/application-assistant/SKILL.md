# Application assistant

Codex prepares the validated plan internally and uses the browser only when it is `ready_for_fill`. Fill exact plan values and upload exact approved paths. Stop for any listed stop, unknown question, CAPTCHA, MFA, access challenge, legal attestation, or unexpected consent. Show the completed application and audit in ordinary language. After the user explicitly approves this application, Codex handles the bound authorization token, clicks submit once, and records real confirmation evidence.
